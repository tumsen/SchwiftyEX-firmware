# SchwiftyEx firmware

Official firmware releases for **SchwiftyEx** by [SchwiftyThing](https://schwiftything.com).

You don't need to download anything here: on the device, open **Settings → Firmware Update →
Check for updates** (the device must be on a Wi‑Fi with internet). It shows the new version and
what changed, and installs only when you press **Install**. Each image is checked against the
SHA‑256 published with its release before it is activated.

Prefer a file? Download `firmware.bin` from a release and use **Update from a file** on the same
Settings page.

**New unit?** The printable one-page guide: [SchwiftyEx-Get-started-A4.pdf](SchwiftyEx-Get-started-A4.pdf).

This repository holds release binaries and the Get started guide only.
